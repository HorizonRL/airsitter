# AirSitter

Pick the best airplane seat — which side gets the sunrise or sunset, the countries and ocean you'll see,
a seat-to-window map for 16 aircraft, a walk-in 360° cabin view and a satellite Earth view along your route.

**Live app:** https://horizonrl.github.io/airsitter/

**Install on Android:** open the link in Chrome → menu (⋮) → *Install app* / *Add to Home screen*.
It then opens full screen from its own icon and works offline after the first visit
(the flight lookup and satellite imagery still need a connection).

**Install on a PC:** in Chrome or Edge, click the install icon at the right of the address bar.

The code lives in [`web/`](web/) — see [web/README.md](web/README.md) to run it locally. Every push to `main`
is built and published to GitHub Pages by [.github/workflows/deploy.yml](.github/workflows/deploy.yml).
